# <img src="/public/favicon.svg" width="24"> [Bake n' Shake](https://bakeandshake.netlify.app) <img src="/public/favicon.svg" width="24">
Interactive 2D Game that let's you run your own bakery.

## Prerequisites
`node@v22`   
`npm@v10.9`

## Development

To run the app:
```bash
npm i
npm run dev
```

To build the app:
```bash
npm run build
```
